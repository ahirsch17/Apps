# College Schedule Patterns & Product Implications

## The Reality: Class Schedules Are Predictable

### Standard Class Meeting Patterns

**MWF (Monday/Wednesday/Friday)**:
- Most common for 50-minute classes
- Examples: CALC 1225, CHEM 1035, ENG 1105
- Usually on the hour: 9am, 10am, 11am, 12pm, 1pm, 2pm, 3pm

**TR (Tuesday/Thursday)**:
- Most common for 75-minute classes  
- Examples: CS 1114, HIST 1115, PSYC 1004
- Usually: 9:30-10:45am, 11am-12:15pm, 12:30-1:45pm, 2-3:15pm, 3:30-4:45pm

**MW (Monday/Wednesday)**:
- Less common, usually 75-minute classes
- Similar timing to TR

**F (Friday only)**:
- Labs (2-3 hours)
- Special sessions
- Usually afternoon: 1-4pm, 2-5pm

**Online/Async**:
- No fixed meeting time
- Student picks when to watch lectures

## Critical Product Insight

### The Pattern Problem

**What happens**:
- Week 1: Emma opens Between, sees "Sarah free 12-1pm today"
- Week 2: Emma realizes "Oh, Sarah is free 12-1pm EVERY Monday/Wednesday/Friday"
- Week 3: Emma and Sarah just text "d2?" every MWF at noon
- **Emma doesn't need Between anymore**

**This accelerates the engagement cliff!**

**Before I knew about patterns**: "App becomes useless after 3-4 weeks"  
**After knowing about patterns**: "App becomes useless after 1-2 weeks"

---

## How to Leverage This (Not Fight It)

### 1. Show Recurring Patterns Explicitly

**Bad (current)**:
```
Free later today
12:00 - 1:00pm
With Sarah
```

**Good (pattern-aware)**:
```
Recurring overlap (Every M/W/F)
12:00 - 1:00pm
With Sarah, Mike

Tap to add to calendar
```

**Why better**:
- Helps users form habits faster (good!)
- Provides MORE value upfront (helps with activation)
- Clear CTA: "Add to calendar" = export value, we're done here

---

### 2. Different UI for MWF vs TR Days

**Monday/Wednesday/Friday view**:
- Emphasize: Quick breaks between classes
- Show: Coffee, lunch, short study sessions
- Typical gaps: 1 hour

**Tuesday/Thursday view**:
- Emphasize: Longer study blocks, gym sessions
- Show: 2-3 hour windows for deep work
- Typical gaps: 1.5-2 hours

**Friday view**:
- Emphasize: "After classes" social plans
- Show: Evening events, weekend kickoff
- Highlight: Who's done with classes when

---

### 3. Weekly Pattern View (New Feature)

**Instead of just "Today"**:
```
Your Week
├── M/W/F: Lunch crew (Sarah, Mike) 12-1pm
├── T/R:   Study block (Sarah, Rachel) 2-4pm
└── Friday: Free after 2pm (8 friends)
```

**This is MORE useful than daily view**:
- See patterns at a glance
- Form consistent friend groups
- Plan week, not just day

---

### 4. Embrace the Churn (It's a Feature)

**New positioning**: Between is for **forming habits**, not maintaining them.

**User journey**:
- Week 1: "Who's free when?"
- Week 2: "Oh, same people every MWF!"
- Week 3: "Cool, we have a lunch group now"
- Week 4: Stops using app (SUCCESS!)

**Metrics shift**:
- OLD: Retention at 30 days (bad: 20%)
- NEW: "Time to friend group formation" (good: 2 weeks)
- NEW: "Lasting friendships formed" (survey at 3 months)

**Virality becomes key**:
- User 1: Forms group, stops using → SUCCESS
- User 2 (their friend): Downloads app to join group
- User 3: Needs to find different group → KEEPS USING
- Cycle continues

## Product Implications

### Feature: "Your Recurring Windows"

**Show on Monday morning**:
```
This week's overlaps

M/W/F: Lunch (12-1pm)
├── Sarah
├── Mike
└── Jenna
Perfect for: Quick meal, catch up

T/R: Study block (2-4pm)
├── Sarah
├── Rachel
└── Alex
Perfect for: Group study, project work

Friday: After classes (3pm+)
├── 8 friends free
└── IM Volleyball @ 6pm
Perfect for: Social, events, weekend kickoff
```

**Benefits**:
- Users see the full picture
- Can plan their week
- Know when to expect certain people
- Don't have to check app daily

---

### Feature: "This Week vs Next Week"

**Important for schedule changes**:
```
⚠️ Heads up: Your schedule changes next week

Current: M/W/F free 12-1pm with Sarah
Next week: M/W/F Sarah has a different class
          But T/R you're both free 1-3pm!
```

**Why this matters**:
- Class schedules change semester to semester
- Drop/add period (first 2 weeks)
- Users need to re-discover overlaps

**Engagement hook**: 
- Start of each semester = re-onboarding
- "Your schedule changed, here are new overlaps"

---

### Feature: "Day Type Awareness"

**Monday morning**:
```
It's Monday (M/W/F pattern)

```

## Updated Personas with Pattern Awareness

### Emma's Journey (Pattern Learning)

**Week 1, Monday**:
- Opens app: "Sarah free 12-1pm"
- Texts Sarah, gets lunch
- Thinks: "Cool, found someone for today"

**Week 1, Wednesday**:
- Opens app: "Sarah free 12-1pm" (again!)
- Realizes: "Wait, same time?"
- Checks: Every Monday/Wednesday/Friday
- **Lightbulb moment**: "We have the same MWF schedule!"

**Week 2, Monday**:
- Doesn't open app
- Just texts Sarah directly: "d2?"
- They meet up
- **Pattern established, app not needed**

**But then...**

**Week 2, Tuesday**:
- Different day, different pattern
- Opens app: "Rachel free 2-4pm"
- New study buddy for T/R days!
- **App still valuable for discovering NEW patterns**

**Result**: Uses app for 2-3 weeks, forms multiple friend groups (MWF lunch crew, T/R study group), then stops using app.

---

### Jake's Journey (Real-time Still Matters)

**Even with patterns, Jake needs real-time presence**:

**Tuesday, 1:30pm**:
- Knows Mike is usually free T/R at 2pm
- Knows they usually study together
- BUT: Is Mike actually on campus TODAY?
- Opens app: "Mike at Starbucks"
- **Pattern tells him WHEN, app tells him IF**

**Why Jake keeps using it**:
- Living off-campus = doesn't know who's actually around
- People skip class, go home, have appointments
- Pattern = prediction, app = confirmation
- "Mike is usually free, but is he HERE?"

## Updated Engagement Strategy

### Week 1: Pattern Discovery
- "Here's everyone you overlap with"
- "Sarah is free every M/W/F at lunch"
- **Goal**: Form 2-3 recurring groups

### Week 2-3: Habit Formation
- Recurring groups meet up
- Pattern established
- **Goal**: Groups don't need app anymore

### Week 4+: Different Use Cases
**For on-campus students (Emma)**: Stop using app (SUCCESS!)
- They have their crews now
- Re-engage at semester start (schedule changes)

**For off-campus students (Jake)**: Keep using app
- Real-time presence still valuable
- "Who's actually on campus?"
- Coordination layer, not discovery

## Design Changes Needed

### 1. Home Screen: Add "This Week" View

**Current**: Only shows "Today"
**Better**: Show recurring patterns for the week

```
Today (Monday)
├── Lunch with Sarah - 12pm
└── Coffee with Mike - 3pm

Your Recurring Windows
├── M/W/F: Lunch crew (12-1pm)
├── T/R: Study block (2-4pm)
└── Friday: Social (after 3pm)
```

### 2. Add Pattern Detection

When showing overlaps, indicate if they recur:

```
Sarah
Free 12-1pm
🔄 Repeats every M/W/F ← NEW
```

### 3. Calendar Export

"Add recurring lunch to calendar"
→ Creates recurring calendar event
→ User doesn't need to check app anymore
→ We successfully EXPORTED the value

### 4. Day-of-Week Context

UI should change based on day:

**Monday**: "M/W/F vibe - quick breaks between classes"
**Tuesday**: "T/R vibe - longer study blocks"  
**Friday**: "Last push! Who's free after classes?"

## Updated Metrics

### Old Metrics (Wrong):
- 30-day retention ← BAD, people SHOULD churn
- Daily active users ← BAD, success = stop using

### New Metrics (Right):
- Time to first friend group formed ← Want this LOW
- Lasting friendships at 3 months ← Want this HIGH
- Semester re-engagement rate ← Want this HIGH
- Invite rate before churning ← Want this HIGH

**Success looks like**:
- User active for 2 weeks
- Forms 2-3 recurring groups  
- Invites 3 friends
- Stops using app
- **Re-engages next semester** (schedule changed)

## Key Takeaway

**The pattern structure HELPS us, if we design for it**:

1. **Accelerates value** - Users find their groups faster
2. **Clear success metric** - Friend group formed = win
3. **Semester cycle** - Built-in re-engagement (schedule changes)
4. **Viral loop** - Users invite friends before churning
5. **Honest positioning** - "We help you form habits, not maintain them"

**Don't fight the churn. Embrace it.**

**New tagline**: "Between: Find your people in 2 weeks, not 2 months."
