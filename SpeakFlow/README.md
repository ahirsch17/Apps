# SpeakFlow

Spoken practice in Spanish, German, Italian, or Tagalog. Each language keeps its own progress. Hear a phrase, say it three times, then answer a short conversation. A key is only for live Call, Text, and a short note after a miss.

## Tabs

| Tab | Needs API key? | Description |
|-----|----------------|-------------|
| Practice | No | Hear a Spanish phrase, say it three times to check it off, then answer a short spoken scene. |
| Path | No | Topic, tense, and which phrases are familiar. |
| You | No | Language, level, optional OpenAI key. Call and Text appear here after four scenes. |

## Install

Open `SpeakFlow.xcodeproj`, set your signing team, run on an iPhone (iOS 17+).
