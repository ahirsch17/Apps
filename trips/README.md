# Trips

Static trip-planner app. Open `index.html` in a browser, or browse the folder on GitHub.

| Path | What |
|---|---|
| [index.html](index.html) | Home. Links every trip. |
| [brazil-argentina-2027/](brazil-argentina-2027/) | Rio, Paraty, Iguazu, Buenos Aires · Apr 2027 |
| [germany-2026/](germany-2026/) | HYROX Karlsruhe, Oktoberfest, Berlin · Sep 29 to Oct 6, 2026 |
| [template/](template/) | Blank page in the same layout |
| [shared/trip.css](shared/trip.css) | Shared styles |
| [RULES.md](RULES.md) | Hard filters the agent must follow |

## New trip

1. Copy `template/index.html` to `trips/<slug>/index.html`.
2. Put photos in `trips/<slug>/photos/`.
3. Fill hero, route, day cards, budget, flights, when to buy, laundry, bags, sun, hotel map pins.

Live share copies can stay a single HTML file with CSS inlined from `shared/trip.css`.

The old root file `brazil-argentina-sister-trip.html` redirects here.
